# Mini Page Nexus

Mini Page Nexus is an AI-powered landing page builder designed for marketers, affiliates, and content creators.

## Features

- Landing page generation
- Responsive design
- React-based architecture
- Tailwind CSS styling
- Component-based UI
- Fast deployment

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- shadcn/ui

## Installation

```bash
npm install
npm run dev
